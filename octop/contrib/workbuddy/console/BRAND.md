## 四、UI组件规范

### 侧边栏导航
- **激活态**：左侧金色短竖线（3px宽×16px高）+ 金色文字 + 淡金色背景
- **hover态**：深色背景 + 白色文字
- **默认态**：透明背景 + 次要文字

### 按钮
- **主按钮**：金色实色背景 + 深色文字（#1A1208）+ 6px圆角 + 36px高
- **次按钮**：透明背景 + 边框 + 次要文字
- **图标按钮**：32×32 + 8px圆角

### 任务列表项
- **布局**：紧凑两行（标题+元数据）
- **激活态**：深色背景 + 边框
- **hover态**：显示右侧操作按钮（⋯）

### 输入框
- **高度**：32px（小）/ 36px（中）/ 大输入框自适应
- **圆角**：6px（普通）/ 12px（Composer大输入框）
- **边框**：subtle（默认）→ 金色（focus）

### 标签/徽章
- **圆角**：999px（完全圆角）
- **内边距**：3px 8px（小）/ 4px 10px（中）
- **字号**：11px / 12px

### 弹窗/Modal
- **背景**：深色（#3A3B40）
- **圆角**：12px
- **遮罩**：rgba(0,0,0,0.6) + 模糊
- **动画**：缓入（ease-out 0.2s）

## 六、文案风格指南

### 语气
- **友好专业**：不过分俏皮，保持可信度
- **简洁直接**：少用感叹号，多用句号
- **用户视角**：用"你"而非"您"

### 示例
```
✅ 今天想让我帮你做什么？
✅ 任务已完成，可在右侧查看产物
✅ 执行完成。可在右侧查看产物与预览。
❌ 哇！您的任务超级棒！！！
❌ 系统已成功完成任务执行流程
```

## 七、设计原则

1. **克制的强调**：金色只用于重要操作和激活态，不滥用
2. **呼吸感**：卡片间距充足，不拥挤
3. **一致性**：圆角/间距/字号遵循固定刻度
4. **深色优先**：以深色主题为主，浅色主题为辅
5. **国潮元素**：保留川剧变脸熊猫IP，但不过度装饰
